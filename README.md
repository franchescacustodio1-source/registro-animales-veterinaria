### Sistema de Registro de Animales para Veterinaria
Autora: Franchesca Lebrón Custodio

### Descripción del proyecto
El Sistema de Registro de Animales para Veterinaria es una aplicación desarrollada en C# que tiene como finalidad facilitar la administración de mascotas, propietarios, veterinarios y consultas médicas. El sistema permitirá organizar la información de los pacientes y llevar un registro de sus servicios veterinarios.

### Objetivo general
Desarrollar un sistema que permita gestionar de manera organizada la información de las mascotas y sus propietarios, así como registrar las consultas, vacunas, diagnósticos y visitas veterinarias.

### Funcionalidades principales
Gestión de mascotas: registrar, consultar, actualizar y eliminar información de los animales.

Gestión de propietarios: almacenar y administrar los datos de los dueños de las mascotas.

Gestión de veterinarios: registrar y consultar la información de los profesionales.

Gestión de consultas: registrar las consultas y los diagnósticos veterinarios.

Control de vacunas: llevar un historial de las vacunas administradas a cada mascota.

Historial de visitas: consultar las visitas y los servicios veterinarios recibidos.
